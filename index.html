装置トラブル対応エージェント

装置のトラブルを質問すると、AIが設備台帳・マニュアル・保全記録を自分で調べて、根拠つきで対処を答えます。部品の交換など現場で直せないときは保全依頼を作りますが、登録は人が承認してから行います。

画面のモックを動かす → 質問の例を押すと、AIが道具を選んで調べ、答えるまでの流れを再現します。承認カードも試せます。 仕組みと設計を読む → 全体の仕組み、4つの道具、ループ、人の承認、失敗したとき、ログまでを図解でまとめました。

できること

  • 調べる順番をAIが決める：設備台帳で装置を特定し、型番のマニュアルと、その装置の保全記録を探す
  • 根拠つきで答える：マニュアルの章と保全記録の番号を添える
  • 書き換えは人の承認を待つ：保全依頼の登録だけは、承認カードで止まる
  • 分からないことは推測しない：台帳に無い装置は「見つからない」と答える
  • 記録が残る：どの道具をどの順で使ったかを、後から追える

使っている技術

  • Claude API の Tool Use（Function Calling）、自分で実装したエージェントのループ（承認で止めて再開、上限10回）
  • Python、Streamlit、SQLite

# 装置トラブル対応エージェント（見せる用）

製造現場の担当者が装置のトラブルを質問すると、AIが **設備台帳・マニュアル・保全記録を自分で調べて**、根拠つきで対処を答えるエージェントです。部品の交換など現場で直せないときは保全依頼を作りますが、**登録は人が承認してから**行います。

このリポジトリは「見せる用」です。画面のモックと、仕組み・設計の資料だけを置いています。**コードは公開していません。**

## できること

- **調べる順番をAIが決める**：設備台帳で装置を特定し、型番のマニュアルと、その装置の保全記録を探す
- **根拠つきで答える**：マニュアルの章と保全記録の番号を添える
- **書き換えは人の承認を待つ**：保全依頼の登録だけは、承認カードで止まる
- **分からないことは推測しない**：台帳に無い装置は「見つからない」と答える
- **記録が残る**：どの道具をどの順で使ったかを、後から追える

```
担当者：「ライン3の充填機でエラーE-12が出た。どうすればいい？」

エージェント：
  1. 設備台帳を調べる      … ライン3の充填機 → 設備ID EQ-003、型番 FL-200
  2. マニュアルを探す      … FL-200 のマニュアルで E-12 → 5.3章「ノズルの洗浄手順」
  3. 保全記録を探す        … EQ-003 の E-12 → ML-0007「洗浄で直らず、Oリング交換で復旧」
  4. 回答：まず5.3章の手順で洗浄。再発するならOリングの交換を（根拠：5.3章、ML-0007）
  5. 交換の依頼が要るなら、保全依頼を作る → 画面で人が承認してから登録
```

## 使っている技術

- Claude API の Tool Use（Function Calling）。ツール4つを定義し、エージェントのループを自分で実装（承認で止めて再開、上限10回、エラーはAIに返す）
- Python、Streamlit、SQLite

## データ

すべて架空です（設備5台、マニュアル3冊、保全記録12件）。実在の装置・会社とは関係ありません。
